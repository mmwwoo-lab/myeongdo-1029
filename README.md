# 명도재 창작 그림전시

공개 홈페이지: https://myeongdojae-art-music-1029.korea8014lee.chatgpt.site

명도재 주인장 이명우의 그림과 음악 전시. 작품 영상 15편을 산수와 바다, 인물과 교감, 호랑이의 기품, 설치와 꽃으로 구성했습니다.

- 주제 필터, 작품·음악 검색, 작품별 감상문과 영상 재생
- 작가 소개(공백 포함 500자), 초상화와 낙관을 넣은 팸플릿
- 전시 안내 영상과 다운로드
- 모바일 반응형 화면, 자동 소리 재생 없음

index.html, style.css, app.js, data.js는 빌드 없이 실행합니다. 이미지와 영상은 공개 Sites 주소에서 불러옵니다. 기존 code_artifact.html 및 myeongdo-1028 자료는 보존했습니다.

음악은 합성 음원이며, 작품 감상문은 AI 작성 글로 실제 평론가의 기고문이 아닙니다. 소개 제목은 전시를 위해 붙였습니다.
