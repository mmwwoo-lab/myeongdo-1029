# Autumn Poetry · The Wind Autumn Leaves Behind

A Korean digital poetry book by Myeongdojae Lee Myeong-woo.

Open `/autumn-poetry/` from the myeongdo-1029 website. The folder uses an English URL; the poems remain in Korean.

## Contents

- 30 contemporary everyday-life poem proposals in 4 parts
- 11 adaptations based on supplied titles/excerpts and 19 new poem proposals
- Commentary, image concepts and image/music production prompts
- 128-page reader, contents navigation, browser speech and print/PDF output
- `manuscript.md`: complete Korean poem proposals and short editorial readings

## Status

The author has yet to approve the proposals. Actual paintings, recordings, scores, QR originals and final publishing metadata are pending. Browser speech uses device voices; availability depends on the device. Editing is saved only in the visitor’s browser and does not change the shared published book.

## Files

`index.html`, `style.css`, `art.svg`, `revision-data.js`, `app.js` run without a build step. The fixed base path is `/autumn-poetry/`.
